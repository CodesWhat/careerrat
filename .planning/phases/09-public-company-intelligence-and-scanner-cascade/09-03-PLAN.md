Output: Deterministic extractor, cascade orchestrator, public-intel writes, and scan route.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Public URL -> scanner | External HTML/text is untrusted input. |
| Scanner -> public-intel DB | Extracted metadata becomes durable local public state. |
| Scanner -> source config | Supported ATS metadata must not write private source config in this plan. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-09-07 | Spoofing | Careers URL links | high | mitigate | Safe URL checks and provider validation reused from resolver. |
| T-09-08 | Denial of Service | Public fetch | medium | mitigate | Timeout, redirect cap, text cap, and no AI on failed fetches. |
| T-09-09 | Tampering | Custom page metadata | medium | mitigate | Confidence/provenance/freshness retained; ambiguous conflicts go to review. |
| T-09-10 | Information Disclosure | Public scan payload | high | mitigate | Public-intel scrub runs before writes. |
