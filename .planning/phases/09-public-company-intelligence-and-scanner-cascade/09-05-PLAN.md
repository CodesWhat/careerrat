## Trust Boundaries

| Boundary | Description |
|---|---|
| Review UI -> decision verb | User action changes public metadata/review state or supported ATS approval. |
| Review item -> source config | Only validated supported ATS can cross into private source config. |
| Escalation metadata -> chat | Marking escalation must not silently launch chat. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-09-15 | Tampering | Review decisions | high | mitigate | expectedVersion conflict checks and decision history. |
| T-09-16 | Elevation of Privilege | Use supported ATS | high | mitigate | Re-run deterministic provider validation before source-config write. |
| T-09-17 | Denial of Service | Review queue | medium | mitigate | Clean no-results excluded; suppress action available. |
| T-09-18 | Repudiation | Escalation | medium | mitigate | Escalation is recorded explicitly without hidden runtime start. |
</threat_model>
