## Trust Boundaries

| Boundary | Description |
|---|---|
| Onboarding UI -> preference verb | User consent state becomes local DB state. |
| Mixed metadata -> public table | Internal resolver/scanner objects are scrubbed into public payloads. |
| Public table -> sync preview | Exportable payload is derived from public tables only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-09-01 | Information Disclosure | Public-intel tables | high | mitigate | Allowlist/denylist scrub and tests block candidate, tracker, comp, fit, notes, paths, prompts, model text, page bodies, and postings. |
| T-09-02 | Tampering | Sync preference | medium | mitigate | Preference route validates booleans and writes through DB verb. |
| T-09-03 | Repudiation | Public metadata provenance | medium | mitigate | Schema includes provenance/freshness/confidence and updated timestamps. |
| T-09-04 | Elevation of Privilege | Sync preview | high | mitigate | Preview uses public-intel reads only and tests fake private rows to prove exclusion. |
| T-09-SC | Tampering | npm installs | low | accept | No package installs. |
</threat_model>
