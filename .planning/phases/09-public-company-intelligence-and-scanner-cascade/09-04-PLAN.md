## Trust Boundaries

| Boundary | Description |
|---|---|
| Public text -> model provider/proxy | Sanitized public text leaves local machine only when AI route is configured and eligibility passes. |
| Model output -> validator | Model output is untrusted until schema and deterministic validation pass. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-09-11 | Information Disclosure | AI prompt | high | mitigate | Prompt builder accepts sanitized public text only; scrub tests scan prompts/envelopes. |
| T-09-12 | Tampering | AI output | high | mitigate | JSON Schema plus deterministic URL/provider validation before write. |
| T-09-13 | Denial of Service | AI fallback | medium | mitigate | Eligibility gates and max one retry. |
| T-09-14 | Repudiation | AI-assisted metadata | medium | mitigate | Store AI-used flag, schema status, confidence, input hash, and review reason without raw text. |
</threat_model>
