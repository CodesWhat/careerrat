## Trust Boundaries

| Boundary | Description |
|---|---|
| Provider/manual form text -> question capture | External form labels are normalized into answerable or excluded packet questions. |
| Answerable questions -> bounded AI | Non-EEO questions and local context become finite answer proposal prompts. |
| AI answer proposal -> markdown artifact | Proposed prose becomes packet content only after evidence and placeholder validation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-10-03-01 | Information Disclosure | `filterAnswerableQuestions()` | high | mitigate | Deterministically exclude provider and manual self-identification prompts before answer drafting. |
| T-10-03-02 | Tampering | `draftPacketAnswers()` | high | mitigate | Require schema-validated answer proposals plus evidence IDs or gap markers, then run document validators. |

| T-10-03-04 | Information Disclosure | Bounded AI envelopes | high | mitigate | Tests require safe envelopes with no raw prompt, model text, current compensation, or private-only fields. |
| T-10-SC | Tampering | npm installs | low | accept | No package installs. |
</threat_model>
