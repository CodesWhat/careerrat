## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Lane state DB to setup readiness | User-edited lane states determine setup readiness and app guidance. |
| Setup UI to Deep ingest workbench | User follows setup CTAs into source intake and proposal review. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Tampering | Readiness evaluator | high | mitigate | Evaluator accepts only canonical terminal statuses and requires reasons for deferred/not-available terminal states. |
| T-08-02 | Spoofing | Onboard state | medium | mitigate | Onboard route derives readiness from the same evaluator as Deep ingest route; no duplicate boolean source. |
| T-08-03 | Repudiation | Deferred/not-available states | medium | mitigate | Returned todos/gaps include reason text and lane key so user-visible readiness can be audited. |
| T-08-04 | Elevation of Privilege | Deep ingest completion bypass | high | mitigate | Nonterminal statuses and missing reasons keep `deep_ingest_complete` false in route tests. |
| T-08-05 | Information Disclosure | Setup details | medium | mitigate | Readiness details show lane labels/reasons only, not raw source chunks or private local-path contents. |
| T-08-06 | Denial of Service | Readiness computation | low | mitigate | Evaluator consumes normalized lane-state rows only; oversized sources are handled before this boundary. |
| T-08-SC | Tampering | npm installs | low | accept | No package install is needed. |
</threat_model>
