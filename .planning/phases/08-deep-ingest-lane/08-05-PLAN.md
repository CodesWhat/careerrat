<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Proposal builder output -> proposal DB rows | Schema-valid proposal/manual/gap payloads become reviewable state before confirmation. |
| Proposal rows -> confirmed DB rows | Untrusted proposal content becomes reusable only after explicit user decision and validation. |
| Browser decisions -> DB verbs | Decision payloads can attempt stale writes or invalid lane transitions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-01 | Elevation of Privilege | Confirmation route | high | mitigate | Require explicit action, expectedVersion, current proposal lookup, and validator rerun before trusted writes. |
| T-08-02 | Tampering | Edited proposal payloads | high | mitigate | Revalidate edits and block confirmation when quote/source support is missing or mismatched. |
| T-08-03 | Information Disclosure | Confirmed output rows | high | mitigate | Privacy validator blocks current-comp/private/protected/local-path content before persistence. |
| T-08-04 | Repudiation | Proposal decisions | medium | mitigate | Persist decision action, at/by metadata, previous status, and reason in SQLite. |
| T-08-05 | Denial of Service | Decision payload size | medium | mitigate | Route body caps from Plan 08-03 apply to decision payloads. |
| T-08-06 | Tampering | Lane terminality | high | mitigate | Lane-state validator prevents terminal readiness without valid completed/deferred/not_available status and reason when required. |
| T-08-07 | Elevation of Privilege | Proposal route | high | mitigate | Proposal route persists review state only and cannot call trusted candidate write verbs. |
| T-08-SC | Tampering | npm installs | low | accept | No package install is needed. |
</threat_model>
