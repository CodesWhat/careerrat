<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to Deep ingest API | User-controlled source text, URLs, file metadata, and proposal edits cross into local API routes. |
| Proposal UI to trusted DB writes | Untrusted proposal data becomes eligible for durable facts only after explicit user action. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Tampering | Proposal editor | high | mitigate | UI requires explicit review/edit/confirm action before `decideDeepIngestProposal` can persist trusted rows. |
| T-08-02 | Information Disclosure | Source preview | high | mitigate | Preview renders local-path requests and private/unreadable outcomes as metadata/gaps, not raw private file contents. |
| T-08-03 | Spoofing | Target shape selector | medium | mitigate | Selector sends canonical target keys only; display labels are not trusted by the API. |
| T-08-04 | Denial of Service | Source textarea/file control | medium | mitigate | UI displays route-level source-size failures from Plan 08-03 and keeps retry/manual fallback visible. |
| T-08-05 | Information Disclosure | Candidate comp and honesty fields | high | mitigate | Proposal cards expose only schema-approved fields; current-comp/private keys blocked by backend validators remain visible as gaps, not persisted values. |
| T-08-06 | Elevation of Privilege | Chat/skill runtime bypass | high | mitigate | No UI action calls `/api/chat/*` or `/api/skill/run`; tests assert these routes are absent from Deep ingest wrappers. |
| T-08-SC | Tampering | npm installs | low | accept | No package install is needed. |
</threat_model>
