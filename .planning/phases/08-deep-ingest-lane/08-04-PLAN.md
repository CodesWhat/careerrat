<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Source chunks -> bounded AI | Untrusted extracted text crosses into optional model calls. |
| Model output -> proposal rows | Schema-valid model output still needs local validation before review. |
| Proposal rows -> UI | Unsafe proposal text can be rendered and edited by the user. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-01 | Tampering | Prompt/source boundary | high | mitigate | Fixed system prompts, source-as-data formatting, no model tools, schema validation, and injection fixtures. |
| T-08-02 | Tampering | Model proposal content | high | mitigate | Grounding validator requires source IDs and quote/span support before confirmation eligibility. |
| T-08-03 | Information Disclosure | AI payload/telemetry | high | mitigate | Source text is capped; usage rows/envelopes are metadata-only; tests reject raw source/model/private content leakage. |
| T-08-04 | Information Disclosure | Privacy validator | high | mitigate | Validator blocks current-comp/private/protected/local-path content from reusable proposals. |
| T-08-05 | Denial of Service | AI context/output size | medium | mitigate | Max source chars, max tokens, lane-specific maxItems, and schema complexity limits. |
| T-08-06 | Elevation of Privilege | Proposal builders | high | mitigate | Proposal builders return proposal/manual/gap payloads only and cannot call trusted candidate write verbs. |
| T-08-SC | Tampering | npm installs | low | accept | No package install is planned; existing bounded AI helpers are reused. |
</threat_model>
