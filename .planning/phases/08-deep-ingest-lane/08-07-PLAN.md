<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Library UI to Deep ingest API | User-controlled source text and chosen target shape cross from a trusted-looking Library page into untrusted scan/proposal routes. |
| Deep ingest DB to Library snapshot | Reviewed DB rows become visible dashboard/library content. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Tampering | Library projection | high | mitigate | Projection filters to confirmed/trusted rows only; pending/rejected/failed rows remain excluded. |
| T-08-02 | Spoofing | Target shape choice | medium | mitigate | UI submits canonical keys and backend validators from Plans 08-03/08-04 reject invalid target shapes. |
| T-08-03 | Information Disclosure | Library cards | high | mitigate | Current-comp/private/local-path leakage validators run before confirmation; projection does not read raw source chunks into card body. |
| T-08-04 | Repudiation | Evidence-flow add | medium | mitigate | Submitted source rows retain source context, target key, and proposal decision history from DB verbs. |
| T-08-05 | Elevation of Privilege | Direct trusted writes | high | mitigate | Library sends sources only to proposal routes; tests assert no direct trusted DB write path is used. |
| T-08-06 | Denial of Service | Large Library paste | medium | mitigate | Source caps and manual fallback from Plan 08-03 apply; UI renders returned cap errors without retry loops. |
| T-08-SC | Tampering | npm installs | low | accept | No package install is needed. |
</threat_model>
