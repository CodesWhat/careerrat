## Trust Boundaries

| Boundary | Description |
|---|---|
| DB verbs -> SQLite | Untrusted source/proposal JSON becomes local durable state. |
| CLI/data -> DB verbs | CLI payloads can attempt invalid lane/proposal transitions. |
| Proposal state -> trusted facts | This plan stores proposal state but must not promote trusted candidate facts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-01 | Tampering | Deep ingest JSON tables | high | mitigate | JSON constraints, generated-column guards, enum validation, and node:test coverage reject malformed source/proposal/lane payloads. |
| T-08-02 | Information Disclosure | Stored source metadata | high | mitigate | Store artifact paths/metadata separately from outbound evidence and keep raw source bodies local; later privacy validators gate proposal display and confirmation. |
| T-08-03 | Denial of Service | Source/proposal rows | medium | mitigate | Persist scanner caps and chunk metadata; reject oversized payloads at route layer in Plan 08-03. |
| T-08-04 | Elevation of Privilege | Proposal decisions | high | mitigate | Expected-version checks and separate confirm verbs prevent bypassing review. |
| T-08-05 | Information Disclosure | Current-comp/privacy fields | high | mitigate | DB validators reject known private field names and Plan 08-05 repeats privacy checks before trusted writes. |
| T-08-06 | Tampering | Migration ordering | high | mitigate | Task requires inspecting current migrations and running real temp DB migration tests before downstream work. |
| T-08-SC | Tampering | npm installs | low | accept | No new package installs are planned; research package audit lists none. |
