<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| User/browser -> Deep ingest API | Pasted text, files, URLs, repo links, local paths, and target-shape choices cross into local backend code. |
| Deep ingest scanner -> network/filesystem | URL fetches and local path reads can expose private network or local data if not constrained. |
| Scanner/proposal -> bounded AI | Source text is untrusted data sent to an optional provider/proxy with metadata-only telemetry. |
| Proposal -> trusted candidate DB state | User-confirmed decisions are the only path from proposals into reusable facts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-01 | Tampering | Source text and prompts | high | mitigate | Tests require source text treated as data, fixed schemas/labels, no model tools, and no source-instruction execution. |
| T-08-02 | Information Disclosure | URL fetcher | high | mitigate | Tests require safe schemes, private/local host rejection, redirect validation, byte/time caps, and explicit unsafe-source outcomes. |
| T-08-03 | Information Disclosure | Local path scanner | high | mitigate | Tests require explicit local path input, normalized paths, metadata preview, and gaps for unreadable/private paths. |
| T-08-04 | Denial of Service | Upload/source scanner | high | mitigate | Tests require request, file, chunk, repo-file-count, byte, and timeout caps with 413 or gap outcomes. |
| T-08-05 | Tampering | Proposal extraction | high | mitigate | Tests require source IDs, supporting quote/span checks, confidence, and blocked confirmation for ungrounded proposals. |
| T-08-06 | Information Disclosure | Telemetry/proposal/logs | high | mitigate | Tests scan envelopes/usage rows for raw source bodies, local paths, current compensation, contact details, protected-trait text, and raw model text. |
| T-08-07 | Elevation of Privilege | Proposal confirmation | high | mitigate | Tests assert proposal generation cannot call trusted candidate writes and confirmation requires explicit decision verbs. |
| T-08-SC | Tampering | npm installs | low | accept | Research says no new runtime packages; no package-manager install task exists in this plan. |
</threat_model>
