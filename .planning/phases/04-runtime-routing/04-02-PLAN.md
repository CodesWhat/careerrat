<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to runtime config route | UI consumes read-only runtime capability data that may reflect local env state. |
| runtime config to React controls | Capability booleans decide which AI/chat controls are visible or disabled. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05 | Spoofing | Runtime capability derivation | medium | mitigate | Use server-provided runtime config fields, not hardcoded React skill lists or key-only inference. |
| T-04-06 | Information Disclosure | OnboardingPage capability state | low | mitigate | Store only booleans, route kind, and skill names; never display or retain secrets. |
| T-04-07 | Denial of Service | Onboarding load | low | mitigate | If runtime config read fails, keep manual/local onboarding usable and disable AI/chat affordances. |
</threat_model>
