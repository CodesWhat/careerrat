<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to runtime config route | Untrusted browser asks for capability data; route must remain read-only and non-starting. |
| environment to UI capability payload | Local env vars determine AI route and skill allowlists; response must expose capability booleans without secrets. |
| browser to retained skill runtime | POST /api/skill/run still accepts untrusted JSON and must keep allowlist/body/SSE guards. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Information Disclosure | GET /api/runtime/config | medium | mitigate | Return only route kind, booleans, and skill names; never serialize API keys, proxy tokens, prompts, or env values. |
| T-04-02 | Elevation of Privilege | POST /api/skill/run | high | mitigate | Keep existing `resolveAllowedSkills()` allowlist behavior and focused POST regressions green. |
| T-04-03 | Denial of Service | POST /api/skill/run | medium | mitigate | Preserve existing 1MB body cap, heartbeat, and abort behavior; do not touch these paths. |
| T-04-04 | Repudiation | Runtime selection | low | mitigate | Config route makes local/chat/full runtime availability explicit so later UI work does not hide runtime selection. |
</threat_model>
