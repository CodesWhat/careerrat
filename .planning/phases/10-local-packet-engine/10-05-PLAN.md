## Trust Boundaries

| Boundary | Description |
|---|---|
| Source markdown -> renderer | Internal packet markdown is rendered into user-facing PDF/DOCX files. |
| Export request -> filesystem | User-controlled format requests create files below the local workspace. |
| Exported artifact path -> DB row | Generated paths become application artifact metadata shown in the app. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-10-05-01 | Tampering | Exported artifact paths | medium | mitigate | Export service writes deterministic workspace paths and registers them through DB verb validation. |
| T-10-05-02 | Information Disclosure | Rendered packet files | high | mitigate | Export only after source artifact validation; tests scan current compensation/private sentinels before stamping ready exports. |
| T-10-05-03 | Denial of Service | DOCX/PDF rendering | medium | mitigate | Use existing export helper and focused tests; no new renderer dependency or package upgrade. |
| T-10-05-04 | Repudiation | Export metadata | medium | mitigate | Manifest records formats, generated timestamps, and source path lineage. |
| T-10-SC | Tampering | npm installs | low | accept | No package installs; existing Playwright/pandoc/soffice/built-in paths are reused. |
</threat_model>
