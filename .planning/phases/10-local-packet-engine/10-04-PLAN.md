<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Packet generation request -> DB write | User request causes local artifact files and application artifact metadata to be written. |
| Local evidence/deep-ingest/proposals -> outbound prose | Mixed candidate material can influence generated artifacts only after confirmation/evidence checks. |
| Private/local context -> generated artifacts | Candidate-private data, current compensation, raw ingest, proposed claims, and local-only notes are read locally but must not leave the app or be stamped as outbound packet prose. |
| Source markdown -> packet preview/export | Internal source artifacts become readable through packet routes and later export rendering. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-10-04-01 | Tampering | `generatePacket()` | high | mitigate | Validate source artifacts with existing placeholder, forbidden wording, evidence, and ATS-safety checks before stamping. |
| T-10-04-02 | Information Disclosure | Packet context | high | mitigate | Treat unconfirmed raw/proposed ingest as gap context only; outbound claims require confirmed evidence IDs. |
| T-10-04-03 | Repudiation | Artifact registration | medium | mitigate | DB verb logs activity and generated timestamps for packet artifacts. |
| T-10-04-04 | Elevation of Privilege | Packet generation route | high | mitigate | Route prepares artifacts only and tests forbid submit/browser/full-runtime side effects. |
| T-10-04-05 | Tampering | Artifact paths | medium | mitigate | Manifest schema restricts artifact paths to workspace-safe values consumed by existing packet resolver. |
| T-10-04-06 | Tampering | Cover-letter prose proposals | high | mitigate | `packetCoverLetterProposalSchema` requires prose blocks plus confirmed evidence IDs; invalid or empty blocks become `NEEDS YOU` gaps before scaffold assembly. |
| T-10-04-07 | Tampering | Question capture lineage | medium | mitigate | `generatePacket()` consumes persisted question capture metadata and records answer lineage in the manifest. |
| T-10-04-08 | Information Disclosure | `generatePacket()` source map | high | mitigate | Tests require every D-08 source class to be enumerated while blocking current compensation, private candidate data, raw/proposed material, and unconfirmed claims from generated artifacts, route envelopes, and accepted AI output. |
| T-10-SC | Tampering | npm installs | low | accept | No package installs. |
</threat_model>
