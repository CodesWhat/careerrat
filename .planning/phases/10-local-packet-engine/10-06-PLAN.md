<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Byte-static page -> local API | Browser UI sends packet and answer requests to new local routes. |
| Local API response -> DOM | Packet status, errors, manual metadata, and answer text are rendered in static pages. |
| Product default -> retained runtime boundary | UI must not silently start broad skill runtime for ordinary packet work. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-10-06-01 | Elevation of Privilege | Packet/answer page default actions | high | mitigate | Tests and static guard require local API defaults and no ordinary retained-runtime launch. |
| T-10-06-02 | Tampering | API response rendering | medium | mitigate | Preserve existing textContent-style rendering and inline script syntax tests; do not inject raw HTML answer text. |
| T-10-06-03 | Information Disclosure | Excluded question display | medium | mitigate | Display skipped metadata only; do not render drafted self-identification answers. |
| T-10-06-04 | Repudiation | Packet status display | low | accept | Local packet route returns generated timestamps and status; UI is read-only and does not need separate audit state. |
| T-10-06-05 | Tampering | Page question-capture state | medium | mitigate | Page tests require question capture IDs/manifest metadata to be passed to generation or reloadable by application ID before generated answers appear. |
| T-10-SC | Tampering | npm installs | low | accept | No package installs. |
</threat_model>
