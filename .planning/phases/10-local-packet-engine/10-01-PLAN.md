## Trust Boundaries

| Boundary | Description |
|---|---|
| UI/client -> packet APIs | Untrusted request bodies ask local routes to gate, capture questions, generate answers, generate packets, and export files. |
| JD/form/company text -> bounded AI | Untrusted external text enters prompts for finite gate and answer judgments. |
| AI output -> artifacts/DB | Model JSON can influence outbound prose only after schema and deterministic validators pass. |
| Artifact path -> packet preview/download | Stamped paths are resolved under the local workspace and exposed through packet routes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-10-01 | Elevation of Privilege | Packet UI runtime path | high | mitigate | RED static/page tests require ordinary packet actions to call local APIs and prepare artifacts only, preserving explicit retained runtime outside this path. |
| T-10-02 | Tampering | Gate/answer bounded AI output | high | mitigate | RED tests require JSON schemas, local validation, evidence IDs, and manual/review envelopes before DB/artifact writes. |
| T-10-03 | Information Disclosure | Candidate facts and compensation | high | mitigate | RED tests scan responses/artifacts for current compensation/private sentinels and require confirmed evidence-only outbound claims. |
| T-10-04 | Information Disclosure | EEO/demographic answers | high | mitigate | RED tests require provider and manual self-identification prompts to be excluded before answer drafting. |
| T-10-05 | Tampering | Artifact paths | medium | mitigate | RED tests require workspace-confined artifact paths and collapse unsafe paths to missing. |
| T-10-06 | Denial of Service | Packet route bodies | medium | mitigate | RED route tests require capped JSON parsing and 400/413-style local failures. |
| T-10-SC | Tampering | npm installs | low | accept | Research recommends no new package installs; this plan creates tests only. |
</threat_model>
