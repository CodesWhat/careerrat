</objective>

<threat_model>

## Trust Boundaries

| Boundary | Description |
| --- | --- |
| paste input -> classifier | User-pasted text or URL enters classification logic. |
| classifier -> bounded helper | Prompt, schema, and labels enter the AI helper. |
| helper -> classifier | Untrusted model classification returns as candidate data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-02-05-01 | Tampering | pasted content prompt | high | mitigate | Preserve prompt rule that pasted content is data, never instructions. |
| T-02-05-02 | Tampering | classification output | high | mitigate | `runBoundedAI()` validates against `config/intake-classify.schema.json` before returning domain data. |
| T-02-05-03 | Repudiation | intake labels | high | mitigate | Tests assert exact `skill`, `action`, and `operation` labels. |
| T-02-05-04 | Denial of Service | no-AI path | medium | mitigate | No-AI produces a needs-user manual classification instead of blocking capture. |

</threat_model>
