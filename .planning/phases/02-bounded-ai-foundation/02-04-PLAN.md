## Phase Goal

**As a** Rolester app surface, **I want to** call cheap bounded AI primitives, **so that** users receive consistent success, manual, and error envelopes without launching full skills.

<objective>
Migrate the lowest-risk current bounded route, `POST /api/assist/suggest`, onto the shared helper and envelope.

Purpose: The phase needs an end-to-end exemplar route that proves app routes can call a cheap bounded AI primitive without launching a full skill. Assist suggestions are tool-less, low-turn, and already hermetically tested.
Output: Assist route uses `runBoundedAI()`, route tests assert the envelope, and the web API wrapper keeps targeting suggestions usable.
</objective>
