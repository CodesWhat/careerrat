<threat_model>

## Trust Boundaries

| Boundary | Description |
| --- | --- |
| bounded helper -> `callAI()` | Helper sends schema-constrained native request. |
| provider -> bounded helper | Provider returns text that may be refusal, truncation, or invalid JSON. |
| bounded helper -> routes | Helper exposes only locally validated `data`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-02-03-01 | Tampering | native-preferred parser | high | mitigate | Parse and validate native provider text locally before success per D-14. |
| T-02-03-02 | Information Disclosure | retry/error body | high | mitigate | Do not include raw native replies in schema failure envelopes. |
| T-02-03-03 | Repudiation | native call labels | high | mitigate | Pass strict `skill` and `action` labels into `callAI()` and preserve route `operation` in envelope metadata. |
| T-02-03-04 | Denial of Service | native retry loop | medium | mitigate | Keep retry count bounded at one corrective retry by default. |

</threat_model>
