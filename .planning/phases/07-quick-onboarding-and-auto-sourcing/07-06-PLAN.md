## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> `/api/sourcing/*` | User actions start local scanner work and read run state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-05 | Tampering | Run state route writes | high | mitigate | Route delegates to DB verbs and returns stable status envelopes. |
| T-07-06 | Repudiation | Duplicate first-run clicks | medium | mitigate | Service reuses running/completed first-search runs and records summaries/errors durably. |
| T-07-07 | Elevation of Privilege | Hidden browser/auth sourcing | high | mitigate | Service imports and tests forbid chat, skill runtime, discovery handoffs, browser capture, and authenticated source execution. |
