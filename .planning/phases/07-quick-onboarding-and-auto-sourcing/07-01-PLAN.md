## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser file upload -> local API | Untrusted DOCX bytes and filenames cross into local file storage and parsing. |
| DOCX parser -> candidate artifact | Extracted text can unlock `search_ready` through `source-resume`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Tampering | DOCX upload filename | high | mitigate | Tests require sanitized filenames and storage only under `workspace/intake/resume-uploads/`. |
| T-07-02 | Denial of Service | DOCX decompression/input size | high | mitigate | Tests require capped raw body reads and 413 before parser invocation. |
| T-07-03 | Information Disclosure | DOCX external references/parser output | medium | mitigate | Tests require raw text extraction only and no AI route for DOCX. |
| T-07-04 | Tampering | `source-resume` readiness | high | mitigate | Tests require `candidateArtifactPut({ id:"source-resume" })` only after usable extraction. |
| T-07-SC | Tampering | npm installs | high | mitigate | This plan installs nothing; approved `mammoth` installation is isolated to Plan 07-04 with package audit evidence. |
</threat_model>
