| Boundary | Description |
| --- | --- |
| proposal state to source config | User decision can cross from pending proposal data into canonical source config only on supported approval. |
| source-config to generated tracker exports | DB/source-config owners may export state; tests must reject direct generated-file writes from proposal code. |

| T-05-08 | Elevation of Privilege | invalid decisions | high | mitigate | Tests cover stale, missing, decided, unsupported, and review-only failures. |
| T-05-09 | Repudiation | non-approval decisions | medium | mitigate | Tests prove reject/suppress/escalate/refresh update proposal state without confirmed writes. |
</threat_model>
