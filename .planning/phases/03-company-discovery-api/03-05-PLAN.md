## Proposal Object Contract

All proposal records returned by the gate and consumed by Plan 03-06 decisions must use these camelCase fields:

`proposalId`, `company`, `why`, `roleFamily`, `roleSeen`, `careersUrl`, `jobBoardUrl`, `atsProvider`, `classification`, `confidenceTier`, `provenance`, `scanSummary`, `jdCapture`, `proposedAction`, `reviewReasons`, `rejectReasons`, `capturedOffers`, `version`.

Allowed `classification` values: `supported_ats`, `unsupported_public`, `unresolved`, `rejected`.
Allowed `confidenceTier` values: `high-confidence`, `borderline`, `rejected`.
Allowed `proposedAction` values: `approve-supported-ats`, `review`, `reject`, `suppress`, `refresh`, `escalate`, `cache-only`.

<threat_model>

## Trust Boundaries

| Boundary | Description |
| --- | --- |
| scanner output -> proposal gate | Public ATS job data affects proposal confidence. |
| candidate compensation floor -> gate | Private local config affects internal eligibility checks. |
| proposal generation -> filesystem | Captured JD bodies are written under workspace artifacts. |
| proposal gate -> API caller | Gate results are presented as actionable proposal states. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-03-05-01 | Tampering | proposal confidence | high | mitigate | High-confidence requires supported provider, current role proof, clean dedupe/exclusion, JD capture status, and comp plausibility. |
| T-03-05-02 | Information Disclosure | compensation privacy | high | mitigate | Use `minimum_base` or configured floor internally and test that `current_base` is never read or returned. |
| T-03-05-03 | Information Disclosure | captured JD artifacts | medium | mitigate | Store JD bodies locally under workspace artifact paths and expose paths/status, not raw bodies in route errors. |
| T-03-05-04 | Elevation of Privilege | proposal generation | high | mitigate | Tests prove captured offers are not persisted as sourced rows before approval. |
| T-03-05-05 | Spoofing | unsupported pages | high | mitigate | Unsupported public pages remain review/cache-only and cannot receive supported ATS approval action. |

</threat_model>
