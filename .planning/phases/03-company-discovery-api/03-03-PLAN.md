## Trust Boundaries

| Boundary | Description |
| --- | --- |
| seed/manual input -> resolver | Untrusted company names and domain hints enter URL resolution. |
| resolver -> public HTTP | Resolver may fetch public homepages and redirects. |
| resolver -> DB cache | Validated resolution/provenance enters durable cache state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-03-03-01 | Information Disclosure | `resolveCompanyBoard` fetch target | high | mitigate | Reject unsupported schemes, localhost/private hosts, and unsafe redirect targets before supported promotion. |
| T-03-03-02 | Tampering | provider classification | high | mitigate | Use `inferProvider()` and require post-redirect provider identity before `supported_ats`. |
| T-03-03-03 | Denial of Service | resolver fetch loop | medium | mitigate | Cap redirects to 3 and fetch timeout to 8000ms through injected fetch options. |
| T-03-03-04 | Elevation of Privilege | seed URL hints | high | mitigate | Treat `domain_hint` as a discovery hint only; no seed field can authorize writes or final URL trust. |
