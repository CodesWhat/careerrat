## Trust Boundaries

| Boundary | Description |
| --- | --- |
| caller -> `/api/discovery/company-proposals` | Untrusted JSON body enters local route. |
| route -> core proposal orchestration | Parsed request crosses into deterministic code. |

| scanner -> proposal response | Public ATS role data influences confirm-first proposal metadata. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-03-01-01 | Denial of Service | proposal route body | high | mitigate | Use `readJsonBodyCapped()` and enforce `COMPANY_DISCOVERY_BATCH_MAX = 12`. |
| T-03-01-02 | Elevation of Privilege | proposal generation | high | mitigate | Tests assert generation does not call source-config writes, sourced writes, chat runtime, or full skill runtime. |
