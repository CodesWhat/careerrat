<threat_model>

## Trust Boundaries

| Boundary | Description |
| --- | --- |
| caller -> decision endpoint | Untrusted decision JSON requests a state change. |
| decision endpoint -> source config | Approved supported ATS proposal mutates canonical source config. |
| decision endpoint -> sourced rows | Captured jobs become tracker-visible sourced rows. |
| refresh decision -> public resolver/scanner | Refresh may re-fetch public board state before updating proposal state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-03-06-01 | Tampering | decision state | high | mitigate | Require `expectedVersion`, pending status, and matching proposal id before mutation. |
| T-03-06-02 | Elevation of Privilege | approval action | high | mitigate | Only high-confidence supported ATS proposals with approval action can call `companyAtsUpsert()`. |
| T-03-06-03 | Tampering | sourced row promotion | high | mitigate | Convert stored captured offers through existing sourced persistence helpers and `sourcedUpsertBatch()`. |
| T-03-06-04 | Repudiation | reject/suppress/refresh decisions | medium | mitigate | Persist decision reason metadata, refresh reason, timestamps, and proposal version increments. |
| T-03-06-05 | Elevation of Privilege | refresh action | high | mitigate | Refresh reruns resolver/scanner/gate but tests prove it cannot write source config or sourced rows. |

</threat_model>
