## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI/CLI/agent caller to local routes | Callers choose between local APIs, DB verbs, bounded AI, chat, and full skill runtime. |
| Full skill runtime route | `POST /api/skill/run` can invoke broader tool surfaces and must remain allowlisted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-07 | Elevation of Privilege | `POST /api/skill/run` policy | high | mitigate | Policy keeps full skill runtime allowlisted and directs deterministic/bounded work to local owners. |
| T-01-08 | Denial of Service | full skill runtime overuse | medium | mitigate | Policy requires cheapest-correct route selection and reserves full skill sessions for workflows that need tools, long orchestration, or user-watched behavior. |
| T-01-09 | Tampering | bounded AI route guidance | medium | mitigate | Policy requires schema validation through `runStructuredOneshot()` before downstream code consumes structured model output. |
| T-01-SC | Tampering | package installs | low | accept | No package-manager install task exists in this plan; executor must not add npm, pip, or cargo installs while creating the planning artifact. |
