## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AI seed output to deterministic resolver | Model-proposed company seeds cross into code-owned URL resolution. |
| Public career pages to scanner/cache | Fetched web content crosses into local cache, scanner offers, and JD capture paths. |
| Proposal to source write | User confirmation is required before supported ATS additions are written. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04 | Tampering | `companySeedSchema` | medium | mitigate | Contract states model output is untrusted seed data and final URLs/write decisions belong to deterministic resolver and confirmation paths. |
| T-01-05 | Information Disclosure | bakeoff and source artifacts | medium | mitigate | Contract keeps candidate-specific discoveries in workspace/source config paths and does not route them into shipped docs such as `docs/SOURCES.md`. |
| T-01-06 | Spoofing | resolver URL fetches | medium | mitigate | Contract requires future resolver validation for scheme, host, provider identity, timeout, provenance, and failure counters before cache promotion. |
| T-01-SC | Tampering | package installs | low | accept | No package-manager install task exists in this plan; executor must not add npm, pip, or cargo installs while creating the planning artifact. |
