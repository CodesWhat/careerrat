| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-11-06 | Elevation of Privilege | `/api/skill/run` POST body | high | mitigate | Validate tool-heavy profile requests before SSE starts and require named retained workflow classification per D-02. |
| T-11-07 | Information Disclosure | `/api/runtime/config` | medium | mitigate | Return only profile names, tool names, and booleans; never return secrets or credential paths. |
| T-11-08 | Repudiation | Chat runtime handoffs | medium | mitigate | Use an explicit chat profile and keep chat availability tied to visible handoff routes per D-04. |
| T-11-SC | Tampering | npm installs/upgrades | high | mitigate | No dependency changes are planned; package changes require the legitimacy checkpoint from 11-RESEARCH.md. |
</threat_model>
