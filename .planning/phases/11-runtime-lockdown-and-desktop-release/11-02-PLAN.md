## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local HTTP route -> Agent SDK | `runSkillStream()` converts app/server calls into SDK tool authority. |
| Runtime profile -> host filesystem/shell | Tool selection determines whether the SDK can mutate files or run commands under bypass mode. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-03 | Elevation of Privilege | `runSkillStream()` default tools | high | mitigate | Remove broad mutation/shell tools from the default profile per D-01 and prove with `tests/skill-runtime.test.mjs`. |
| T-11-04 | Tampering | Explicit tool overrides | medium | mitigate | Preserve narrow caller-supplied tools per D-03 and copy arrays before SDK use. |
| T-11-05 | Elevation of Privilege | `permissionMode: bypassPermissions` | high | mitigate | Keep bypass mode bounded by resolved app-safe tools and require explicit tool-heavy selection per D-05. |
| T-11-SC | Tampering | npm installs/upgrades | high | mitigate | No dependency changes are planned; follow the 11-RESEARCH Package Legitimacy Audit before any install or upgrade. |
</threat_model>
