## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Electron renderer -> main process | Navigation and window-open events cross from rendered app content into host OS actions. |
| Packaged app -> local filesystem | Packaged resources are signed/read-only while user data, SQLite, and BYOK state must live under `CAREERRAT_HOME`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-09 | Elevation of Privilege | `shell.openExternal` | high | mitigate | Validate external URL schemes before opening and deny malformed or unsafe targets per Electron guidance. |
| T-11-10 | Information Disclosure | Packaged data root | medium | mitigate | Resolve packaged user data under Electron `userData`, outside signed resources, before engine imports; verify SQLite and BYOK paths land under that root. |
| T-11-11 | Denial of Service | Desktop smoke startup | medium | mitigate | Preserve recoverable logging and nonzero exit on smoke failure instead of blank-window success. |
| T-11-SC | Tampering | npm installs/upgrades | high | mitigate | No dependency changes are planned; package changes require the legitimacy checkpoint from 11-RESEARCH.md. |
</threat_model>
