## Mac app (Apple Silicon)

The signed, notarized macOS app is the simplest way to run CareerRat on an
Apple Silicon Mac running macOS 12 or newer.

The Windows x64 installer passes build, install, launch, export, and uninstall
QA, but it is not a public release asset yet. SignPath Foundation signing
requires project reputation CareerRat does not yet have. Unsigned CI packages
are QA-only and never public release assets. See the repository's
[Windows status](https://github.com/CodesWhat/careerrat/blob/main/docs/WINDOWS.md)
and [code signing policy](https://github.com/CodesWhat/careerrat/blob/main/docs/CODE_SIGNING_POLICY.md).

Download the `CareerRat-<version>-arm64.dmg` from the
[latest release](https://github.com/CodesWhat/careerrat/releases/latest), or
install it with Homebrew:

```bash
brew install --cask codeswhat/tap/careerrat
```

CareerRat needs one supported local AI tool. If neither is installed, the Mac app
walks a first-time user through the Claude path itself:

1. Get a paid Claude plan. Pro is enough; Max provides more usage. You can use
   [Scott's disclosed referral](https://claude.ai/referral/rOLHwxlsfA).
2. Click **Install inside CareerRat**. CareerRat runs Anthropic's official native
   installer and shows readable progress without sending you to another app.
3. Click **Sign in**, finish Claude sign-in in the browser, and return to
   CareerRat. The app checks automatically and also provides **Check setup**.

Already use Codex? Expand **I already use another AI tool** and follow its
[official install guide](https://developers.openai.com/codex/cli/).

Claude Code and OpenAI Codex are the two supported product choices. Both run the
same CareerRat-owned workflows and skills against the same durable local state.
The packaged app invokes the selected installed CLI directly and never falls
back to or silently switches providers. A runtime becomes `Ready` only after
local availability, authentication, and its readiness check pass.

After you choose either engine, drop a résumé or start talking. Paul asks only
for missing facts, uses plain English, and gives concrete examples when a choice
is abstract. As soon as role and location targeting are usable, CareerRat starts
the first search in the background. Finishing setup opens Search with a clear
running, matches-found, retry, or start state, so you never have to ask whether
the job search has begun.

Open the app and it scaffolds your workspace, boots the local app at
`http://localhost:7777`, and launches your agent with a starter message, the
same first run described below for the npm path.

The Mac app checks GitHub once a day for a newer signed release, downloads it
inside CareerRat, and waits for you to choose **Restart and install**. See
[Privacy & Data Boundaries](/advanced/privacy) for the details.

## npm (any platform)

Prerequisites:

- **Node.js >= 24** — check with `node -v`
- **A supported coding-agent CLI on your PATH.** Install any one listed above.
  - Claude Code: `npm install -g @anthropic-ai/claude-code`
    ([claude.com/claude-code](https://claude.com/claude-code))
  - Codex: `npm install -g @openai/codex`
    ([github.com/openai/codex](https://github.com/openai/codex))

You need one supported CLI on your PATH before running `careerrat start`.

```bash
npm install -g careerrat
careerrat start
```

The `start` command does the whole arc in one shot:

1. Scaffolds `candidate/` and `workspace/` directories (idempotent, safe to re-run).
2. Installs the skills so your agent sees `/apply-job`, `/evaluate-job`, etc.
3. Seeds `workspace/tracker.json` from the demo template if not yet present.
4. Boots the live local app at `http://localhost:7777` with event-driven data updates.
5. Launches your agent with a starter message.

## Source checkout

Developing from a source checkout uses the same command shape after linking the
local binary:

```bash
git clone https://github.com/CodesWhat/careerrat
cd careerrat
npm install
npm run hooks:install
npm link
careerrat start
```

### Useful flags

| Flag | Effect |
|------|--------|
| `--no-agent` | Scaffold + local app only, no agent launch |
| `--no-dashboard` | Launch agent only, no local app server |
| `--agent <name>` | Override the agent command launched by the CLI |
| `--port <n>` | Local app port (default 7777) |

## Manual wiring

If you prefer to open your agent yourself:

```bash
careerrat doctor     # verify environment + scaffold state
```

Then open your compatible agent in the repo root and say:

> familiarize yourself and let's get started

The agent reads `AGENTS.md`, verifies the skills shim, and runs `ingest-profile`
conversationally if your candidate profile is not yet set up.

## Custom data location

By default `workspace/` and `candidate/` live inside the cloned repo. Set
`CAREERRAT_HOME` to put them somewhere else:

```bash
export CAREERRAT_HOME=~/careerrat-data
careerrat start claude
```

Everything under `CAREERRAT_HOME` is gitignored and never touches the repo tree.

## Health check

```bash
careerrat doctor
```

Reports environment health (Node version, agent CLI on PATH), skills
discoverability, workspace scaffold state, setup completeness, and any config
schema errors. Run this any time something feels off.
